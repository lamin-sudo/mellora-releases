# Mellora — ميلورا

**أعمال وإبداعات نسائية جزائرية**

تطبيق جزائري يجمع المبدعات وأصحاب المتاجر النسائية، ويتيح للزبونات اكتشاف المنتجات والتواصل المباشر مع البائعات.

---

## 📥 التحميل

حمّلي آخر إصدار (APK لأجهزة Android):

**[⬇ تحميل Mellora v2.7](https://github.com/lamin-sudo/mellora-releases/releases/latest/download/app-release.apk)**

جميع الإصدارات: [صفحة الإصدارات](https://github.com/lamin-sudo/mellora-releases/releases)

> لتثبيت ملف APK، فعّلي خيار «تثبيت من مصادر غير معروفة» في إعدادات الهاتف.

---

## ✨ المميزات

- 🛍️ تصفّح المنتجات والمتاجر النسائية في الجزائر
- 💬 رسائل مباشرة مع البائعات
- 🏪 إنشاء متجر خاص ونشر المنتجات (للبائعات)
- ⭐ تقييم المنتجات والمتاجر
- 👑 نادي ميلورا الملكي: نقاط ومستويات تكافئ نشاطك
- 🔔 إشعارات بالرسائل والتقييمات وتقدّم المستوى
- 🔒 تسجيل آمن بتأكيد البريد الإلكتروني
